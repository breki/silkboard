# html-report

Read [the report template](../html-report-template.html). Use the supplied
material or the relevant conversation; ask only if the intended content is
unclear. Preserve its type scale, light/dark themes, and restrictive CSP.
Escape external text and author markup yourself. Keep the report self-contained
with inline styles and embedded images, no external requests or executable
content. Omit secrets and unnecessary personal data.

Write to the requested local path, or `reports/<topic>.html` with a safe,
single-segment slug. Preserve existing unrelated output; choose a fresh name
if needed. Link the delivered file. Open it only if the environment permits
that operation, and report when visual inspection was not possible. Do not
publish a site or upload a cloud artifact. Add no hosting infrastructure.
