# architect

Read the README, roadmap, architecture proposal, and relevant source if it
exists. Describe current implementation separately from intended design.
Evaluate changes against the deployment-first milestone and dashboard/updater
trust boundaries. Reuse relevant existing project patterns with source evidence.
Do not invent crates or implementation details as if installed. Ask about
unresolved product or deployment choices before making dependent decisions.
Keep accepted decisions in their canonical documents; proposals remain labeled.
This workflow does not provision VMs or expand later milestones.
