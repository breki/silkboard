# docs-audit

Inventory repository documentation and agent guidance, including wrappers.
Check claims against the tree, identify stale duplication, broken references,
unclear ownership, missing decisions, and obsolete material. Read shared
procedures once; assess wrappers for routing rather than treating them as
independent policies. Rate each substantive document keep, trim, revise, or
delete with a concrete reason. Separate proposed design from claims of current
behavior. Report recommendations only; no edits or automatic deletions.
